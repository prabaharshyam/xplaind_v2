# XplAIned.in — The One-Stop AI University & Gamified Career Academy

A futuristic, gamified 3D AI learning platform covering **9 end-to-end AI Career Roles**, **78 deep-dive textbook modules** (with architecture diagrams, interactive flowcharts, playbooks, real enterprise case studies, and comparison matrices), **Top MNC Academies** (Google, Anthropic, Microsoft, DeepLearning.AI, NVIDIA, OpenAI, Hugging Face), **Top AI YouTube Masterclasses** (Mosh Hamedani, Andrej Karpathy, 3Blue1Brown, StatQuest, etc.), and **Interactive AI Sandbox Labs**.

## Quick Start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # serve the production build
```

## Key Features

- **9 AI Career Roadmaps**: AI Engineer, Generative AI & LLM Engineer, Forward Deployed Engineer (FDE), AI Product Manager, Agentic AI Engineer, AI Automation Specialist, AI Governance & Compliance Specialist, Machine Learning Engineer, and MLOps Engineer.
- **Full Textbook Modules (`src/content/deepDiveEngine.ts`)**: Every topic includes deep conceptual breakdowns, 1-click *Explain Like I'm 15 (Zero-Jargon Mode)*, interactive 5-step execution flowcharts, system architecture diagrams, 4-phase practitioner playbooks, real-world company case studies, and trade-off comparison tables.
- **AI University & Global Resource Vault (`/university`)**: Direct links to official courses from Google, Anthropic, Microsoft, DeepLearning.AI, NVIDIA, OpenAI, and Hugging Face, plus curated YouTube masterclasses and ecosystem portals (*There's An AI For That*, *DataCamp*, *Kaggle*, *LMSYS Chatbot Arena*, *Papers With Code*).
- **Interactive AI Arcade (`/arcade`)**: Live browser sandboxes including *Prompt Alchemist*, *Token & Cost X-Ray*, *Agent Loop Stepper*, and a 3-step *AI Role Matcher*.
- **Gamification & 3D UI**: XP, levels, ranks (`Prompt Rookie` to `Singularity Boss`), daily streaks, unlockable badges, 3D scroll-reactive starfield canvas, and 3D tilt cards.
